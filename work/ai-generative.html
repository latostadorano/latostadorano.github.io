AI & Generative

An ongoing experimental series in Midjourney, Stable Diffusion and Runway.

RoleExperimental / Image Generation
ClientPersonal
Year2024–Ongoing

This is the sandbox where I stress-test what generative tools can actually do: prompt craft, image coherence, and how far you can push an aesthetic before it falls apart. Midjourney, Stable Diffusion, Runway, and increasingly Claude for the workflow layer that connects them.

The same series doubles as reference work for AI visual evaluation: assessing lighting, anatomy, composition and narrative alignment in generated imagery, the difference between an image that merely looks impressive for a second and one that actually holds up under a longer look.
