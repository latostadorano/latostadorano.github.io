Weather Postcards

A real-time content automation system built with p5.js and a live Weather API.

RoleCreative Coding & Design
StatusRunning in production
ClientSJRT · Jalisco TV, Radio & News
Stackp5.js · Weather API
Started2025

SJRT publishes daily across TV, radio and social media, including a recurring series of visual postcards tied to that day's editorial calendar: commemorative dates, cultural figures, public-health awareness campaigns. Producing that volume manually was consuming significant design hours every week.

I built a generative visual system in p5.js that pulls live conditions from a Weather API and renders on-brand templates automatically, with color, motion and composition responding to actual weather data rather than static illustration. The system demonstrates design, code and data operating as a single pipeline instead of three separate handoffs.

The system now handles a meaningful share of SJRT's daily postcard production automatically, reducing manual design work by 10+ hours a week and increasing engagement by roughly 30% compared to the previous static templates, freeing the design team to focus on content that requires direct creative input.
